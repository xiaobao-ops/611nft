# 代理池样例 —— 复制为 proxies.txt 并填入真实代理（proxies.txt 已被 .gitignore 忽略）
#
# 当前 50 钱包混合池规则：
#   - 本文件只放 STATIC_PROXY_COUNT 条静态代理；默认示例要求精确 20 条。
#   - 其余 DYNAMIC_PROXY_COUNT=30 条由 PROXY_API_URL 在 Mint 开放后获取，不写入本文件。
#   - 每行一个代理；空行与 # 开头的注释行会被忽略。
#   - 支持 HTTP(S)、SOCKS5H，以及 IP:PORT:USER:PASSWORD 四段式。
#   - dry-run 不连接代理、不调用动态代理 API，也不会检查出口 IP。
#   - armed 模式会在 Mint 开放且 gas 预检通过后检查出口；池不完整或 IP 重复会在 Ticket 前停止。
#
